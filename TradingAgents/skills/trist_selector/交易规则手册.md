## 〇、游资选股总框架

在进入具体规则前，先用股海贼王的**复盘三问**作为第一道筛选：

```
1. 它为什么涨？（逻辑硬不硬？是题材炒作还是业绩驱动？）
2. 它在板块里什么地位？（龙头、跟风、还是补涨？）
3. 它在大盘里什么地位？（主线核心还是边缘杂音？）
```

三问不过关 → 不进入打分流程。

## 〇½、阿布价格行为学（Al Brooks Price Action）v4.0 新增

> 来源：Al Brooks 五本专著 — 蜡烛图、趋势、区间、反转（两本）
> 核心理念：**裸K线是唯一需要的工具。价格行为本身就是答案。**

### 0½.1 市场只有两种状态

| 状态 | 特征 | 阿布策略 |
|------|------|---------|
| **趋势** | 更高的高点/更低的低点，均线缺口（≥20根K线不碰MA20），窄通道 | 顺势做H2/L2，不逆势 |
| **交易区间** | K线大量重叠（≥70%），振幅小，走势混乱 | 区间边界反向操作，不追突破 |

> **不确定性默认假设**：无法判断时，优先假设处于交易区间早期。

### 0½.2 80% 惯性法则（贯穿全体系的核心统计规律）

| 场景 | 80%会发生什么 | 对应操作 |
|------|-------------|---------|
| **交易区间中的突破** | 80%失败 | 反向操作（+6分） |
| **强趋势中的反转尝试** | 80%失败 | 顺势操作（+6分） |
| **任何周期中有效突破** | 仅约10% | 90%都在通道/区间中 |
| 错误操作 | — | **扣6分**（对抗法则） |

### 0½.3 信号K线 ≠ 入场K线（执行铁律）

```
┌──────────────────────────────────────────────────────┐
│  信号K线（Signal Bar）                                │
│  ├─ "预警" — 盘后识别，告诉你"准备入场"               │
│  ├─ 收盘在极端位置、实体饱满、前有回调                 │
│  └─ 不作为入场K线使用                                  │
│                                                      │
│  入场K线（Entry Bar）                                 │
│  ├─ "执行" — 次日价格突破信号K线高/低点+1tick          │
│  ├─ 必须与信号K线不是同一根K线                          │
│  └─ 用止损挂单（Buy Stop / Sell Stop）触发            │
└──────────────────────────────────────────────────────┘
```

### 0½.4 H1/H2/L1/L2 计数系统（阿布独创）

| 信号 | 含义 | 胜率 |
|------|------|------|
| **H1/L1** | 首次回调/反弹 | ⭐⭐ 低（常是陷阱，4分） |
| **H2/L2** | 二段回调/反弹 | ⭐⭐⭐⭐⭐ **黄金标准**（10分） |
| **H3/L3** | 三段推拉（楔形） | ⭐⭐⭐⭐ 高（8分） |
| **H4+/L4+** | 过度回调/反弹 | ⭐ 低（2分，趋势存疑） |

> **逻辑**：H1失败后逆势者二次攻击（H2），再次失败则被迫止损→反手买入→趋势加速。

### 0½.5 特殊K线识别

| 类型 | 识别标准 | 阿布含义 |
|------|---------|---------|
| **强趋势K线** | 实体>70%震幅，收盘在极端，影线极小 | 趋势力极强，顺势（+6分） |
| **Pin Bar** | 单侧长影线>实体2倍，反侧影线极小 | 可能反转，需背景确认（+4.5分） |
| **内包线** | 高<前K高 且 低>前K低 | 蓄力中，突破方向决定走势（+2分） |
| **外包线** | 高>前K高 且 低<前K低 | 多空激烈博弈，下根K线关键（+3分） |

### 0½.6 楔形（阿布最重要的反转形态）

| 类型 | 特征 | 操作 |
|------|------|------|
| **牛/熊旗楔形** | 三推收敛+趋势中 | 顺势中继（+4分） |
| **抛物线楔形** | 加速消耗、窄通道、缺口 | 抢购/抛售高潮→反转概率极大（+8分） |
| **嵌套楔形** | 大楔形内套小楔形 | 多重共振→最高胜率（+8分） |
| **陷阱楔形** | 无K线重叠、趋势极强 | **不是楔形！** 是旗形→顺势 |

### 0½.7 评分模型（PA1-PA13，90分制）

```
一级：市场背景（20分）— PA1趋势(8) + PA2区间(6) + PA3_80%法则(6)
二级：信号K线（30分）— PA4收盘位置(10) + PA5实体(8) + PA6回调(6) + PA7特殊K线(6)
三级：入场结构（25分）— PA8_H计数(10) + PA9楔形(8) + PA10_SR共振(7)
四级：辅助确认（15分）— PA11量能(5) + PA12板块(5) + PA13情绪(5)

强化加分：B1-B9（+0~30分）
外围风险：external（0~10分）

仓位：≥72满仓 | 54-71半仓 | <54观察 | 禁区剔除
```

### 0½.8 执行门禁（不占分，必须通过）

```
GATE-A：价格突破信号K线极值 → 入场执行
GATE-B：入场K线收盘确认方向 → 持仓确认
       未通过 → 挂单作废，不入场
```

### 1.5½ 趋势N字模式（A→B→C 三阶段）v4.1 新增

> 来源：走N模型（悟空真经公众号）— 趋势跟踪专用入场框架
> 核心理念：**标志性阳线启动 → 缩量回调不破支撑 → 突破确认创新高。分批入场，锚定止损。**

#### 第一步：A阳线识别（硬性门槛，三项全过才启动N字模式）

| # | 条件 | 标准 | 性质 |
|---|------|------|------|
| **A1** | 涨幅 | 收盘涨幅 ≥ 6%，优先涨停板（10%）。**ST股绝对排除。** 20cm票可叠加考虑，优先10cm。 | 🔴 硬性门槛 |
| **A2** | 量线 | 5日量线 > 60日量线 | 🔴 硬性门槛 |
| **A3** | MACD | DIF > DEA（红柱状态） | 🔴 硬性门槛 |
| **A4** | 阻力位突破 | 突破平台/颈线/MA55/MA144/下降趋势线，量能配合 | 🟡 辅助加分（不否决） |

> **三项硬性门槛全部通过 → 确认A阳线有效，进入N字模式跟踪。**
> A4 阻力位突破属于主观判断，满足则加分，不满足不影响A阳线有效性。

#### 第二步：B回调质量评估

| # | 维度 | 标准 | 不合格信号 |
|---|------|------|-----------|
| **B1** | 缩量 | 整体持续缩量，单日量能可短暂小幅放大但趋势明确递减 | 单日放量（>A量120%）的长阴线 → **形态破坏** |
| **B2** | 价格 | 调整期最低价 > A阳线开盘价 | 跌破A开盘价 → **N字形态失败** |
| **B3** | K线形态 | 小阴线、小阳线、十字星为主，实体普遍较小。允许1-2根实体稍大阴线但需缩量 | 连续大阴线 → **动能衰竭** |
| **B4** | 均线 | 回踩不破MA20为最佳，MA5/MA10/MA20任一之上企稳均可 | 跌破所有短期均线 → **趋势存疑** |
| **B5** | 时间窗口 | 3-10根K线为佳 | <3根=洗盘不充分；>15根=动能可能衰竭 |

#### 第三步：三梯度买点（趋势跟踪专用，替换S1/S2/S3/S5/S6/S10）

> **仓位按现有幽灵三原则+仓位映射执行，不做替换。**
> 买点1=试探仓 → 买点2=加仓 → 买点3=主仓

| 买点 | 触发条件 | 止损锚定 | 对应旧信号 |
|------|---------|---------|-----------|
| **买点1** 回踩MA企稳 | 缩量至A量**30%**附近 + 企稳K线（长下影/小阳/十字星）+ **在MA5/MA10/MA20任一之上企稳** | 回踩低点下方**3-5%** | S1缩量十字星 + S2 MA5支撑 |
| **买点2** 关键位反转 | 缩量至A量**50%**附近 + 回踩A实体中部（**不能吞没A实体**）+ 止跌反转K线（锤头线/阳包阴） | A最低价下方**2-3%** | S10 机构洗盘V转（替换为更精细规则） |
| **买点3** 突破确认 | C阳线收盘 > A最高价（**创新高**）+ 量能温和放大（≥A量且<A量**200%**）。避免巨量（>200%）滞涨。 | A最高价下方**2%** | S3放量突破 + S6强势突破 |

> **买点递进逻辑**：买点1是左侧试探（缩量极致+均线企稳），买点2是左侧加仓（缩量缓和+关键位反转），买点3是右侧确认（突破创新高）。三者不一定全部触发——买点1和买点2可能只触发一个，买点3是最终确认。

#### 第四步：时间止损

| **T2** | 走势明显弱于预期（持续阴跌/量能异常） | 提前退出，不等时间止损 |

### 1.5¾ 龟兔模型（换手卡一字）— 独立短线连板模式 v4.1 新增

> 来源：悟空真经（第一篇）— 换手卡一字模式
> 定位：**独立于趋势交易系统，短线连板专用。可与龙头战法混合使用。**
> 核心理念：**同板块同身位，一字板为兔子（锚定板块强度），换手板为乌龟（筹码交换卡位）。**

#### 一、前置条件：宏观环境（R1-R2，两者缺一不可）

| # | 条件 | 判定标准 |
|---|------|---------|
| **R1** | 大题材出现 | 有明确的题材催化（政策/技术突破/地缘事件/涨价逻辑等），板块内批量涨停 |
| **R2** | 情绪主升 | 资金做多意愿强烈，9:15开盘瞬时出现**百万手封单**的一字板；场外踏空资金急于入场 |

> **适用场景**：分歧转一致后的主升期 = 最佳。**排除场景**：高潮期（涨停>80家+媒体刷屏）→ 次日容易分化被坑；冰点期 → 无题材无情绪不适用。

#### 二、模式识别：兔龟配对（R3-R6，四个条件全部满足）

| # | 条件 | 判定标准 |
|---|------|---------|
| **R3** | 同板块 | 两只股票属于**同一题材板块**（如军工/航运/固态电池/机器人/房地产/稳定币等） |
| **R4** | 同身位 | 两只股票处于**相同的连板高度**（同一板/二板/三板梯队） |
| **R5** | 兔子 = 大单一字板 | 其中一只为**大单一字板**，封单巨大，次日预期仍是强更强/一字加速。兔子的作用是**锚定板块强度** |
| **R6** | 乌龟 = 换手板 | 另一只为**换手板**，筹码充分交换（换手率明显高于兔子），有辨识度（如大长腿上板打出辨识度） |

> **乌龟识别要点**：
> - ✅ 换手率足够（不能是缩量秒板 → 缩量秒板是兔子二号，不是乌龟）
> - ✅ 有辨识度（大长腿、炸板回封、连续换手板积累）
> - ❌ **地天板不算辨识度，排除**
> - ✅ 筹码结构好（连续换手板积累，筹码平均成本不断抬高）

#### 三、为什么做龟兔？— 一字板与换手板的本质差异

| 一字板（兔子）的问题 | 换手板（乌龟）的优势 |
|-------------------|-------------------|
| 散户参与感低 | 筹码每日交换，散户参与感强 |
| 后期获利盘累计多 | 场内资金不断多翻空、空翻多 |
| 筹码断层 → 开板时由强转弱 | 提供源源不断的对手盘，承接强 |
| 获利盘集中暴力砸盘风险 | 无集中砸盘风险，具备弱转强基础 |

> **龟兔赛跑的核心**：最重要的是"赛跑"二字。只要二者一直在竞争，谁输谁赢就尚无定论。乌龟存在超越兔子甚至取得胜利的**预期**——这个预期就是交易的价值。换手板具备利用筹码优势卡赢一字板的预期。

#### 四、买点（两个）

| 买点 | 触发条件 | 操作 | 前置确认 |
|------|---------|------|---------|
| **买点1** 炸板回封 | 乌龟盘中炸板 → 放量换手 → **回封涨停** | 回封瞬间扫板介入 | 兔子仍一字封死 ✅ |
| **买点2** 换手晋级 | 乌龟未炸板，充分换手后**晋级下一板** | 换手板上板时介入 | 兔子继续一字 ✅ |

> **核心原则**：兔子必须保持一字板状态。兔子开板 = 板块强度减弱 → 模式可能失效，需重新评估。

#### 五、卖点（四个）

| # | 触发条件 | 操作 |
|---|---------|------|
| 卖点1 | 乌龟断板（当日无法封回涨停） | **离场** |
| 卖点2 | 兔子一字打开（不及预期，板块强度减弱） | **减仓/离场**，重新评估 |
| 卖点3 | 高位风险（如10板以上） | **及时止盈**，越高位置卡位意义越小，向上空间有限 |
| 卖点4 | 板上不断漏单 / 封单大幅减少 | **止盈离场** |

#### 六、容错率（龟兔模型核心优势）

> 由于乌龟在上涨过程中不断进行筹码交换，场内筹码平均成本不断抬高，**不会出现严重筹码断层**。即使卡位失败，通常也不会太极端。乌龟有时也会由连板转为**强趋势抱团**走势。

**7个案例验证**：

| 案例 | 乌龟 | 兔子 | 卡位结果 | 利润 |
|------|------|------|---------|------|
| 军工 | 利君股份 | 成飞集成 | ❌ 失败 | ~20% |
| 航运 | 南京港 | 宁波海运 | ✅ 成功 | ~20% |
| 油气 | 山东墨龙 | 准油股份 | ✅ 成功 | 多板 |
| 固态电池 | 兴业股份 | 湘潭电化 | ❌ 失败 | 有溢价+转强趋势 |
| 房地产 | 渝开发 | 四方新材 | ❌ 失败 | 25%+ |
| 稳定币 | 上海物贸 | 兰生股份 | ❌ 失败 | 30%+ |
| 机器人 | 北纬科技 | 国机精工 | — | — |

> **关键发现**：卡位失败 ≠ 亏损。7个案例中即使卡位失败，乌龟仍有充足溢价离场机会。**容错率极高，这是龟兔模型区别于其他短线模式的最大优势。**

#### 七、与龙头战法的混合

> 龟兔模型与龙头战法天然互补。当市场最高板（龙头）为重组利好一字板时，同板块的换手板乌龟可能成为**实际可交易的龙头替代**。此时乌龟既是龟兔模型的乌龟，也是龙头战法的换手龙头。

#### 八、多维度叠加

> 模式只是交易系统的一个维度。符合模式可能胜率只有60%，但同时符合筹码理论的维度可能提高到70%，再符合情绪周期的维度可能又提高到80%。**不断丰富武器库，才能在市场生存。**

#### 九、龟兔模型与趋势N字模型的关系

```
趋势N字模式（1.5½） → 趋势跟踪，日线级别，A→B→C三阶段，盘后识别→次日挂单
龟兔模型（1.5¾）    → 短线连板，盘中实时，兔龟配对，独立于趋势系统

两者并列，互不干扰：
- 趋势票 → 走N字流程，问"三买点在哪"
- 连板票 → 走龟兔流程，问"兔龟配对是否成立"
- 龟兔失败后可能转趋势N字 → 兴业股份案例（连板转强趋势抱团）
```

## 三、仓位管理核心规则 🔴（幽灵的礼物三原则）

> 来源：《幽灵的礼物》（Phantom's Gift）— 华尔街幽灵30年不败的核心秘密
> 级别：**核心规则，与禁区同级，必须无条件遵守**
> 核心理念：**第一笔是试探。市场必须用盈利证明你对了，你才配加仓。**

### 原则一：只持有被市场证明正确的仓位 🎯

> "如果一个仓位没有立刻证明自己是对的，就砍掉它。不要让一笔交易变成'希望交易'。"

| # | 规则 | 执行 |
|---|------|------|
| **G1** | 开仓后第 2 日（T+2）收盘仍亏损 | **减半仓**（同 SL2） |
| **G2** | 开仓后第 3 日（T+3）收盘仍未浮盈（含平盘） | **清仓** — 市场已证明你错了 |
| **G3** | 持仓期间任何时候意识到"我在等回本" | **立即清仓** — "希望"是亏损放大器 |

**逻辑**：你入场是因为判断价格会涨。如果它没涨，你的判断就是错的。不要给错的判断更多时间——砍掉它，下一个机会更好。

### 原则二：只在盈利仓位上金字塔加仓 📐

> "第一笔是试探。市场用盈利告诉你'你是对的'之后，你才能加码。而且每次加码都要比上一次小。"

**加仓三道前置条件（必须同时满足）**：

```
┌─────────────────────────────────────────────┐
│ 条件①  初始仓位浮盈 ≥ 3%                     │
│        市场必须先证明第一笔是对的              │
├─────────────────────────────────────────────┤
│ 条件②  股价重新站上 MA5                       │
│        趋势必须恢复强势                        │
├─────────────────────────────────────────────┤
│ 条件③  出现新的入场信号（S1-S10 任一）         │
│        加仓 = 新开一笔交易，必须有信号支撑       │
└─────────────────────────────────────────────┘
```

**加仓执行规则**：

| # | 规则 | 执行 |
|---|------|------|
| **G4** | 三道前置条件任一不满足 | **禁止加仓** |
| **G5** | 加仓量 ≤ 上一次加仓量的 **50%** | 金字塔结构，底大顶小，绝不倒金字塔 |
| **G6** | 加仓后 → 整体止损立即上移至**加仓均价** | 绝不让盈利仓变亏损仓 |
| **G7** | 加仓后价格回落至加仓均价以下 | **立即退出全部加仓部分**，初始仓位按原止损 |

**金字塔加仓示例**：

```
初始仓位 50%（成本 64.89）
  │
  ├─ 浮盈 ≥ 3%（66.84）+ 站上 MA5 + 入场信号触发
  │   └─ 第一次加仓 ≤ 25%（总仓位 75%）
  │       止损上移至加仓均价
  │       │
  │       ├─ 浮盈 ≥ 8%（70.08）+ MA5 > MA10 强势 + 入场信号触发
  │       │   └─ 第二次加仓 ≤ 12.5%（总仓位 87.5%）
  │       │       止损再上移
  │       │       │
  │       │       └─ ⚠️ 已达 X8 天花板，不再加仓
  │       │
  │       └─ 加仓后跌破加仓均价 → 立即平掉加仓部分
  │
  └─ 条件不满足 → 不加仓，让初始仓位自己跑
```

### 原则三：市场给你意外大礼时要收下 🎁

> "当你看到一笔远超预期的利润时，市场在告诉你'你运气好，不是判断好'。收下礼物，不要贪。"

| # | 规则 | 执行 |
|---|------|------|
| **G8** | 单日涨幅 > 7% | 减仓 **1/3**，锁定意外利润 |
| **G9** | 连续 3 日累计涨幅 > 15% | 减仓 **1/2**，剩余部分跟踪止盈 |
| **G10** | 持仓浮盈突然加速（如 3%→8% 仅用 1 天） | 上移止损至成本价，保护本金 |
| **G11** | 单日放巨量（量比 > 3）但涨幅 < 5% | 减仓 **1/2** — 大概率是出货 |

**逻辑**：暴利不可持续。市场给你超额回报时，大概率是情绪溢价而非基本面变化。收下一部分礼物，用剩下的继续赌趋势。

### 三原则速查

### 3.2 移动止盈

> ⚠️ 与幽灵原则三（G8-G11）联动使用。TP 是按价止盈，G 是按行为止盈。两者同时生效，哪个先触发就执行哪个。

### 3.2.1 幽灵暴利止盈（与 TP 并行，优先执行）

> 来源：幽灵的礼物原则三。暴利 = 运气，不是判断。收下礼物，不要贪。

| # | 幽灵规则 | 执行 | 与 TP 的关系 |
|---|---------|------|------------|
| **G8** | 单日涨幅 > 7% | 减仓 **1/3**，锁定意外利润 | 优先于 TP1-3。即使只浮盈 3%，单日 +7% 也减 |
| ⚠️ | 所有加减仓操作 | **必须为 100 股的整数倍**（A 股 1 手 = 100 股） | 计算时向下取整到百位 |
| **G9** | 连续 3 日累计涨幅 > 15% | 减仓 **1/2**，剩余跟踪止盈 | 优先于 TP2/TP3 |
| **G10** | 浮盈加速（如 1 天从 3%→8%） | 止损立即上移至成本价 | TP1 的前置加速版 |
| **G11** | 放巨量（量比 > 3）但涨幅 < 5% | 减仓 **1/2** | TP 不会触发，但 G11 会 — 这是出货信号 |

```

  ┌──────────┐    ┌──────────┐
  │ TP 按价位 │    │ G 按行为  │

       └───┬───────────┘

    哪个先触发就执行哪个

```

│                                                      │
│  正常波动（盘中跌幅 < 7%）：                            │
│    → 无视盘中波动，等收盘                               │
│    → 收盘价 < 止损位 → 尾盘集合竞价卖出                  │
│    → 收盘价 > 止损位 → 继续持有                         │
│                                                      │
│  极端事件（盘中跌幅 ≥ 7%）：                            │
│    → 立即清仓，不等收盘                                 │
│    → 防止连续跌停无法逃生                               │
└──────────────────────────────────────────────────────┘
```

| 规则 | 条件 | 动作 | 设计意图 |
|:-----|:-----|:-----|:-----|
| 收盘止损 | 收盘 < 止损位 | 尾盘集合竞价清仓 | 过滤盘中洗盘噪音 |
| SL3硬止损 | 盘中跌 ≥ 7% | 立即清仓 | 防连续跌停锁死 |

> ⚠️ 抱团股止损与趋势股止损的区别：趋势股用结构止损+盘中执行；抱团股用收盘价止损+极端跌幅盘中执行。**不要用趋势股的方法做抱团股。**

### 10.6 不买的条件

```
☐ 开盘高开 > 5% → 不追
☐ 5 日涨幅 > 20% → X1 触发
☐ 昨天涨停 → X7 触发（龟兔模型豁免：换手晋级买点不受此限）
☐ 放量杀跌（量比 > 1.5 + 阴线）→ 主力出货
☐ 涨停 > 80 家 → X12 高潮期
☐ G3 心态："再不买就来不及了" → 停手
```
