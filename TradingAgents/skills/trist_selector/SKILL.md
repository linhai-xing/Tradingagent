# Trist Selector v2.0

## Quick Start

```
/trist-selector              # 今日全市场 Top 5
/trist-selector 600522       # 单只股票深度打分
python screener.py            # 命令行直接运行
```

## 执行流程

当用户调用此 skill 时：

### 单股分析
1. 运行 `python screener.py <ticker>` 拉取 K 线 + 市场上下文
2. 展示打分结果：核心/强化/禁区/入场信号/建议仓位
3. 若触发禁区 → 明确告知原因（引用用户交割单数据或游资规则）

### 全市场筛选
1. 运行 `python screener.py --full` 四步漏斗筛选
2. 读取 `output/top5_YYYYMMDD.json`
3. 按排名展示 Top 5，每只附打分详情 + 入场信号

## 打分卡速查

### 核心规则（6 条，各 25 分）

| 规则 | 判定 | 来源 |
|------|------|------|
| C1 趋势 | MA5 > MA20 > MA60，价在 MA5 上 | 赢家 100% MA5>MA20 |
| C2 非追高 | 近 5 日涨幅 < 15% | 输家买前涨 23.9% |
| C3 量能 | 换手 2-20%，量比 0.5-3.0 | 赢家量比 0.98 |
| C4 主线 | 板块 10 日涨幅前 40% | 盈利全在 AI/半导体内 |
| C5 情绪 | 冰点/分歧期满分，一致期 15 分，高潮期剔除 | 炒股养家 |
| C6 龙头 | 板块 Top 3 + 跟涨 ≥ 3 只 = 龙头 | 赵老哥/股海贼王 |

### 强化规则（9 条，各 +10 分）

B1 龙头辨识度 · B2 分歧转一致 · B3 机构背书 · B4 合理回调 · B5 盈利拐点
B6 弱转强 · B7 低位首板 · B8 游资席位共振 · B9 大资金容量

### 绝对禁区（12 条，一票否决）

X1 高位追涨(>20%) · X2 流动性差 · X3 庄股 · X4 利空 · X5 首次接触 · X6 大盘崩
X7 涨停次日 · X8 仓位超 25% · X9 MA5 死叉 · X10 拉萨上榜 · X11 佛山砸盘 · X12 高潮接盘

### 仓位

```
总分 = C1~C6(满分150) + B1~B9(满分90) = 最高240

>= 80  → 满仓   60-79 → 半仓   <60 → 观察   禁区 → 剔除
```

### 入场信号（至少 1 个）

S1 缩量十字星 · S2 MA5 支撑 · S3 放量突破 · S4 分歧转一致 · S5 尾盘企稳
S6 强势突破 · S7 弱转强板 · S8 首阴低吸 · S9 板块联动 · S10 机构洗盘V转

## 交易计划输出格式（必须遵循）

当制定交易计划时，必须使用以下表格格式：

```
📋 交易计划

  ┌──────────────────────────────────────────────────┐
  │  入场: [具体入场条件和理由]                        │
  │                                                  │
  │  [现价分析 + 距离入场位的百分比]                    │
  │  [当前走势描述]                                   │
  │                                                  │
  │  入场区: [价格区间]                               │
  │  = [入场依据1]                                   │
  │  = [入场依据2]                                   │
  │                                                  │
  │  仓位: [百分比]（[仓位理由]）                      │
  │                                                  │
  ├──────────────────────────────────────────────────┤
  │                                                  │
  │  阶段         价格       仓位      止损    触发    │
  │  ─────────────────────────────────────────────   │
  │  入场          [价格]    [仓位]   [止损价] [条件]  │
  │  加仓A         [价格]    [仓位]   [止损价] TP1+5% │
  │  锁利TP2       [价格]    [仓位]   [止损价] +10%  │
  │  移动TP3       [价格]    [仓位]  trailing  +15%  │
  │  止损          [价格]     0%       —      [条件]  │
  │                                                  │
  │  止损选择: [价格] ([止损依据])                     │
  │  = [止损逻辑说明]                                 │
  │  = 总资金风险: [仓位%] × [止损距离%] = [风险%]    │
  │                                                  │
  └──────────────────────────────────────────────────┘
```

**关键要求**：
- 必须包含入场区、入场理由、仓位百分比
- 必须包含 TP1/TP2/TP3 三阶段 + 止损
- 每行必须明确：价格、仓位、止损、触发条件
- 必须计算总资金风险（仓位% × 止损距离%）
