# 交易日志系统

Trist的交易记录和复盘系统。每笔交易记录，每周复盘。

## 目录结构

```
trade_journal/
├── README.md          ← 本文件（使用说明）
├── HISTORICAL.md      ← 历史交易总览（5-6月全部35笔 + 全局复盘）
├── 2026-W34.md        ← 本周交易 + 周复盘
├── 2026-W35.md        ← （下周）
└── ...
```

## 使用方式

### 记录新交易
Trist在对话中告知交易细节 → Claude写入当周文件。

### 每周复盘
每周日/周一，Claude读取当周文件，输出：
1. 本周统计（交易笔数、胜率、盈亏）
2. 规则执行率（哪些交易按规则、哪些违规）
3. 教训整理
4. 规则更新建议

## 记录格式

每笔交易：
```markdown
### 交易N：股票名 — 策略

| 字段 | 内容 |
|:-----|:-----|
| 日期 | YYYY-MM-DD 买入 → MM-DD 卖出 |
| 策略 | 龟兔/N字/趋势/抱团 |
| 买入价 | X.XX |
| 卖出价 | X.XX |
| 盈亏% | **±X%** |
| 触发规则 | 止损/止盈的具体规则 |
| 规则执行 | ✅/❌ |

**复盘笔记：**
- 做对了什么
- 做错了什么
- 教训
```
