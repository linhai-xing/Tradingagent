# Trist Selector v4.1 — 100分制选股 + 独立执行门禁

> 创建：2026-07-23 | 状态：设计完成，转入实现

---

## 动机

v3.0 百合花亏损 -7% 回溯暴露三个系统缺陷：

1. **评分只看方向不看质量**：MA5回踩就买，不区分"结构性回踩"和"恐慌性跳空"
2. **没有入场结构评分**：六连V转后追入=动量耗尽，旧系统无感知
3. **评分系统直接驱动执行**：60分→半仓买入，没有中间拦截层

v4.1 将系统分为两层：评分系统（选股过滤器）+ 执行门禁（硬性关卡）。

---

## 架构

```
100分评分系统（选股过滤器）→ ≥60分可关注
         ↓
执行门禁（三关，不占分）→ 全部通过才下单
```

## 一、100分评分系统

### 一级：市场背景（13分）

| PA | 规则 | 分数 |
|------|------|------|
| PA1 | 趋势强度（EMA排列+均线缺口+K线占比） | 5 |
| PA2 | 交易区间识别（K线重叠度+区间振幅） | 4 |
| PA3 | 80%惯性法则（顺势+4，逆势**-4**） | 4 |

### 二级：信号K线质量（25分）

| PA | 规则 | 分数 |
|------|------|------|
| PA4 | 收盘位置（顶部/底部1/3以内=满分） | 8 |
| PA5 | 实体强度（实体占比+影线方向） | 7 |
| PA6 | 回调确认（前≥2根反向K线） | 5 |
| PA7 | 特殊K线（Pin Bar/内包/外包/强趋势K线） | 5 |

### 三级：入场结构（22分）

| PA | 规则 | 分数 |

| PA9 | 楔形/旗形（三推+嵌套+抛物线） | 6 |
| PA10 | SR共振（均线+前高/低多重重合） | 6 |

### 四级：辅助确认（10分）

| PA | 规则 | 分数 |
|------|------|------|
| PA11 | 量能 | 3 |
| PA12 | 主线/板块 | 3 |
| PA13 | 情绪周期（冰点/分歧满分，一致半分） | 4 |

### 五级：强化（20分）

| 规则 | 分数 |
|------|------|
| B2 分歧转一致 / B6 弱转强 | 各4 |

### 六级：外围风险（10分）

默认10分，触发条件扣分，最低0分。X15触发时一票否决。

```
< 60 → 观察
禁区 → 剔除
```

---

## 三、执行门禁（三关，不占分）

### Gate-A：入场方式

```
✅ 价格突破信号K线高/低点+1tick → 入场
✅ 挂止损单，等着被触发
❌ 竞价买入
❌ 开盘追入
❌ 盘中"感觉差不多"追入

信号K线识别（盘后）→ 次日挂单 → 入场K线触发
信号K线 ≠ 入场K线，不能是同一根
```

### Gate-B：入场后确认

```
✅ 入场K线收盘确认方向 → 持仓
❌ 入场后反向 → 当日减仓或次日清仓
```

### Gate-C：时间窗口

```
✅ 下午 14:00 后执行（75% 胜率模式）
❌ 上午买入（上午胜率 27%）
⚠️ 竞价只在一种情况可用：前日已设止损挂单，竞价触发入场
```

## 四、禁区（15条，一票否决）

X1-X12 不变，X13/X14 交易者纪律，X15 外围风险（外围因子=0且行业相关性>0.5）
