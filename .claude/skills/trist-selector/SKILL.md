## 规则速查

### 评分模型（100分制，PA1-PA13）

**一级：市场背景（20分）**
- PA1 趋势强度（8分）：EMA排列 + 均线缺口(≥20根不碰MA20) + 趋势K线占比
- PA2 交易区间识别（6分）：K线重叠度 + 区间振幅
- PA3 **80%法则（6分）**：顺应+6 / 对抗**-6**（阿布：市场有惯性）

**二级：信号K线质量（30分）** ★新增★
- PA4 收盘位置（10分）：收盘在K线顶部/底部1/3以内
- PA5 实体强度（8分）：实体占比 + 影线方向
- PA6 回调确认（6分）：信号K线前≥2根反向K线
- PA7 **特殊K线（6分）**：Pin Bar/内包线/外包线/强趋势K线

**三级：入场结构（25分）** ★新增★
- PA8 **H1/H2/L1/L2（10分）**：H2/L2黄金标准=满分，H1/L1陷阱=半分
- PA9 楔形/旗形（8分）：三推+嵌套+抛物线楔形
- PA10 SR共振（7分）：均线+前高/低多重重合

**四级：辅助确认（15分）**
- PA11 量能（5分）
- PA12 主线/板块（5分）
- PA13 情绪周期（5分）：冰点/分歧满分，一致半分

### 执行门禁（不占分，阿布核心）

```
信号K线识别 → 次日挂Gate-A止损买单 → Gate-A触发 → 情绪三方案推仓位 → 收盘Gate-B判定

GATE-A: 价格突破信号K线高/低点+1tick → 入场触发
GATE-B: 入场K线收盘后裸K判定（单根趋势K线 or 多根连续阳线）
        ① 实体 ≥ 60% K线振幅
        ② 收盘在K线上方 1/2
        ③ 上影线 ≤ 实体（1:1）
        
        情绪三方案:
          方案一（情绪好）: Gate-A全进 → Gate-B决定明天是否砍
          方案二（情绪一般）: Gate-A进一半 → Gate-B尾盘加一半
          方案三（情绪差）: Gate-A不动 → Gate-B尾盘全进
```

## 阿布价格行为学核心概念

| 概念 | 说明 |
|------|------|
| **信号K线 ≠ 入场K线** | 信号K线是"预警"，入场K线是"执行"，不能是同一根K线 |
| **H2/L2黄金标准** | 牛趋势二段回调后做多 / 熊趋势二段反弹后做空 = 最高胜率 |
| **80%惯性法则** | 趋势中80%反转失败→顺势；区间中80%突破失败→反向 |
| **均线缺口** | 连续20+根K线不碰EMA20 = 强趋势，轻易不要逆势 |
| **特殊K线** | Pin Bar(锤子/倒锤)/内包线(蓄力)/外包线(博弈)/强趋势K线(顺势) |
| **楔形** | 三推结构收敛→反转or旗形中继；抛物线楔形=抢购/抛售高潮 |
